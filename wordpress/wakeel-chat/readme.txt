Adds your self-hosted Wakeel AI assistant to every page: answers customers 24/7 in their dialect, takes orders and bookings.

== Description ==

Wakeel is an open-source AI employee for small businesses. It answers on WhatsApp, Instagram, Messenger, Telegram and your website.
This plugin adds the website chat bubble. You need a running Wakeel server: https://github.com/mashraf1997/wakeel

== Installation ==

1. Upload the plugin and activate it.
2. Go to Settings → Wakeel Chat and paste your Wakeel address, for example https://chat.example.com
3. Save. The chat bubble appears on every page.
